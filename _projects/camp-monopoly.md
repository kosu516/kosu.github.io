**Full-Stack Web Development**

This site runs a Monopoly-style game for high school students attending the NTU Electrical Engineering camp. As part of the 2026 development team, I translated revised game rules into frontend and backend changes covering game mechanics, asset accounting, and administrative controls.

The application stores game state in MongoDB. I added automated Google Sheets backups to safeguard game records after a prior data-loss incident.
